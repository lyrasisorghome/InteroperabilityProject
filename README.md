# Interoperability Project
The CST Interoperability Project is an initiative of the Lyrasis Organizational Home, supported by the Lyrasis CST Growth Fund, in two phases.

Phase I, Technical Specifications, was facilitated by Jessica Farrell and Ryan Morrison-Westphal of Redstart Works consulting.

Phase II, Implementation, will begin in Fall 2026 with the release of RFPs for development work specified in Phase I.

Under the guidance of the Organizational Home and in close consultation with the communities, this project is designed to equitably support each of (5) Lyrasis Community-Supported Technologies (ArchivesSpace, CollectionSpace, DSpace, Fedora, VIVO), centering community, sustainability, and interoperability.

This repository was used to gather user stories and collaborate on technical specifications.


# How to Participate

Phase II, Implementation, will begin in Fall 2026 with the release of RFPs for development work specified in Phase I. Check back then for ways to participate in the project.
