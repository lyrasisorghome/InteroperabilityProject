<center><h1>About the CST Interoperability Project</h1></center>
<hr><center></center>
<p>The CST Interoperability Project supported by the CST Growth Fund,  a million-dollar investment from Lyrasis’ reserves designed to help community-supported technologies (CSTs) grow for the future.</p>

<p>Under the guidance of the Organizational Home and in close consultation with the communities, the project is designed to equitably support  each of these important technologies, and center community, sustainability, and interoperability.</p>

<p>Phase I of the project defines functional requirements for new interoperability features for each CST. Phase II of the project implements these feature designs.</p>

<p>The website shares information and updates as the project develops. There is also a [GitHub repository](https://github.com/lyrasisorghome/InteroperabilityProject) which holds a record of community-requested features proposed during the project, and detailed technical information about selected use cases to pursue. Jessica Farrell and Ryan Morrison-Westphal of [Redstart Works](https://redstart.works), a digital archives consultancy, led phase I and created the website and GitHub repo.</p>
