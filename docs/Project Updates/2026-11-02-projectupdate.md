# Request for Proposals - Implementations
*November 2, 2026*

Lyrasis [seeks one or more proposals](https://lyrasis.org/wp-content/uploads/2026/11/RFP-CST-Interoperability-Project-Phase-II-Implementation.pdf) to implement interoperability features that have been specified in [Phase I of the CST Interoperability Project](https://lyrasisorghome.github.io/InteroperabilityProject/Project%20Updates/2026-9-03-projectupdate/).  

These specifications impact ArchiveSpace, DSpace, and VIVO, and involve the development of new code for ArchiveSpace and VIVO.  This work is funded by Lyrasis through the CST Growth Fund. 

The final deliverables will be submitted to the ArchivesSpace and VIVO communities for review and acceptance. Proposals may cover one, two, or all three of the following work packages and Lyrasis may choose not to fund all.

* Work Package A: Bidirectional Linking between ArchivesSpace and DSpace
* Work Package B: ArchivesSpace SWORD Deposit (DSpace as exemplar)
* Work Package C: VIVO SWORD Deposit (DSpace as exemplar)

For full details and links to the specifications see the [Request For Proposals (RFP) document](https://lyrasis.org/wp-content/uploads/2026/11/RFP-CST-Interoperability-Project-Phase-II-Implementation.pdf).
